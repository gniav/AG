# Автономный рабочий процесс

1. Прочитай DEVELOPMENT_RULES.md и COMMIT_STRATEGY.md, изучи существующий код, состояние Git и ограничения задачи.
2. Определи минимальные самостоятельные этапы и составь рабочий план; для крупной задачи используй PROGRESS_TEMPLATE.md в agent_data.
3. Последовательно реализуй и проверь этапы, применяя подходящие тесты, линтеры и проверки типов. Если локальные коммиты разрешены, коммить каждый полезный этап по стратегии коммитов. Не останавливайся после первого этапа и не спрашивай подтверждение для каждого разрешённого действия.
4. Проверь интеграцию и итоговое состояние проекта. Изучи status, staged diff и новые файлы, убедись, что служебные материалы не попали в коммит и проект не зависит от agent_data.
5. После прерывания изучи Git-историю, актуальные изменения и прогресс, затем продолжи с последнего завершённого этапа, не дублируя работу. Не выполняй push без отдельного разрешения.
